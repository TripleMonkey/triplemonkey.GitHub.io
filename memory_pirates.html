Ahoy, matey! Improve your memory recall with this classic image matching game. Open all of the matching treasure chests to win.

Design, prototyping and iOS development by Nigel Krajewski  ·  Swift, SwiftUI, CloudKit, Core Data and Game Center  ·  iPhone

Challenge yourself to beat your best time and fewest moves, then climb the Game Center leaderboards to be the best among your friends and the world.

The Story

Memory Pirates began as a course project exploring the use of constraints to present views beautifully on any Apple device and in any orientation. Design and prototyping were done in Adobe XD, and the original version was built in Xcode with Swift and UIKit.

I later rebuilt the project with SwiftUI, expecting device sizes and orientations to be easier to handle than they were with UIKit. That turned out to be only half true: SwiftUI views handle size changes more gracefully, but orientation changes remained a challenge to get right.

The current SwiftUI version uses CloudKit for data persistence and Game Center for friendly competition.

Features

  • Classic memory match: flip cards, find pairs and clear the board
  • Game Center leaderboards for the best time and fewest moves, plus achievements
  • Pirate-themed graphics and sound bring every round to life
  • Free to play, no data collected, and rated 4+ for the whole crew
