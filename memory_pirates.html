the story

From course project to App Store

Memory Pirates began as a course project exploring the use of constraints to present views beautifully on any Apple device and in any orientation. Design and prototyping were done in Adobe XD, and the original version was built in Xcode with Swift and UIKit.

I later rebuilt the project with SwiftUI, expecting device sizes and orientations to be easier to handle than they were with UIKit. That turned out to be only half true: SwiftUI views handle size changes more gracefully, but orientation changes remained a challenge to get right.

The current SwiftUI version uses CloudKit for data persistence and Game Center for friendly competition.
